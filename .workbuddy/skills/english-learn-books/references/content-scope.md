# 内容边界与查漏依据

本项目的所有内容都必须落在这份边界之内。查漏时先对照本清单确认「该不该收」，再对照四本书确认「收了没有」。

## 一、广州 / 广东教材与课标

### 小学英语

| 学段 | 教材 | 出版方 | 要点 |
|---|---|---|---|
| 一、二年级 | 《小学英语口语》 | 广州出版社 | 依托地方与学校课程开设口语课，以听说为主，不纳入正式考试，无统一纸质课本要求读写 |
| 三至六年级 | 《义务教育教科书·英语》（三年级起点，广州版） | 教育科学出版社 | 广州市教育局称「教育科学版」，坊间称「教科版（广州版）」；系统听说读写，纳入统考 |

依据：广州市教育局政务咨询答复（jyj.gz.gov.cn，pid=978413）明确「小学阶段从三年级开始学习英语……一二年级英语口语教材版本为广州出版社版本，三至六年级英语教材版本为教育科学版」；广东省教育厅《关于印发义务教育语文等学科教学指导意见（2012 年版）的通知》（粤教教研函〔2012〕9 号）为一二年级设口语课的依据。

**2026 年秋季起广州各年级启用新版教科版教材**，词汇量与语法要求上调（新增一般过去时系统学习、科普/旅行/环保主题词、复合句阅读）。查漏时须以新版为准，不要拿旧版教辅的词表当边界。

**注意区分**：广州小学不用人教版 PEP。PEP 是全国大部分地区使用的版本，本项目只在「版式标准」上参考 PEP（见 typesetting.md），词表与教学进度一律以教科版（广州版）为准。

### 初中英语

| 学段 | 教材 | 出版方 |
|---|---|---|
| 七至九年级 | 《英语》（牛津上海版 / 沪教牛津） | 上海教育出版社，广州、深圳用 |

小学教科版与初中沪教牛津是两套独立教研体系，词汇库、话题、语法框架几乎不衔接——这是本项目分「小学册」与「初中册」两本的根本原因。

### 广州中考（初中学业水平考试）

| 项目 | 现行（2024—2026 方案） | 2027—2029 方案 |
|---|---|---|
| 英语总分 | 120 分（其中听说 30 分） | 140 分（听说 30 分 + 笔试 110 分） |
| 笔试时长 | 100 分钟 | 100 分钟（不变） |
| 听说方式 | 人机对话 | 人机对话；第三部分「信息转述及询问」改为「角色扮演」 |
| 笔试变化 | — | 阅读增设「项目情境」读写综合题；写作「完成句子」改为「语法填空」 |
| 命题依据 | 《义务教育课程方案和课程标准（2022 年版）》 | 同左 |

依据：广州市人民政府与广州招考网公布的《2027—2029 年广州市初中学业水平考试录取计分科目考试实施方案》及政策解读。

**查漏含义**：初中册若涉及中考卷面描述，须核对是否仍写「120 分」「完成句子」等旧口径。

### 课标词汇与语法项目

- 词表依据：《义务教育英语课程标准（2022 年版）》附录词汇表（小学 / 初中分段）与附录语法项目表。
- 本项目分档标记即由此而来：★ 小学核心、○ 小学拓展、◆ KET 核心、● PET 核心。
- 初中册的时态范围以课标语法项目表为准：六种时态（一般现在、一般过去、一般将来、现在进行、过去进行、现在完成），被动语态考前三种时间。**过去完成时不在课标必考范围，只要求认读**。

## 二、剑桥 KET / PET 官方考试范围

KET 正式名 **A2 Key**（中小学版 A2 Key for Schools），PET 正式名 **B1 Preliminary**（中小学版 B1 Preliminary for Schools）。

### 一手依据：Handbook 的 Language specifications

剑桥《A2 Key Handbook for Teachers》与《B1 Preliminary Handbook for Teachers》各有一节明确命名为 **Language specifications** 的附录（A2 约在手册 56–58 页，B1 约在 70–72 页），逐条列出该级会考的语法项目。这是第一手来源，任何坊间清单与它冲突时以它为准。

A2 官方清单分 13 类：Verbs、Modals、Tenses、Verb forms、Clause types、Interrogatives、Nouns、Pronouns、Determiners、Adjectives、Adverbs、Prepositions、Connectives。

### 语法：KET 与 PET 的分界

| 项目 | KET (A2) | PET (B1) |
|---|---|---|
| 时态 | 一般现在、现在进行、一般过去、过去进行、现在完成（just/yet/already/never/ever/for/since）、will/shall、be going to | 再加 was/were going to、used to + inf. |
| 被动 | 一般现在与一般过去的被动 | 再加情态被动（modal passive） |
| 使役 | — | causative have/get |
| 从句 | 主句、并列句；sure/certain、know/think/believe/hope、say/tell 后的 that 从句；if/when/where/because 引导的从句 | 再加宾语从句与间接引语（say/ask/tell，含间接疑问）、定语从句（who/which/that/where/whose） |
| 条件句 | 无独立类别，if 只以最基础的从句形式出现 | type 0、1、2（含 If I were you） |
| 情态动词 | can, could, would, will, shall, should, may, have (got) to, must, mustn't, need, needn't | 再加 might, ought to, used to |
| 短语动词 | 无独立类别，只有基础款 | **单列一类**（compound verb patterns：phrasal verbs / verbs with prepositions），数量明显增多 |
| 连接词 | and, but, or, when, where, because, if | either/or, while, until, before, after, as soon as, since, as, for, so that, in order to, so, so...that, such...that, unless, although |
| 其他 verb forms | 肯定/疑问/否定、祈使句、不定式（带 to 与不带 to）、动名词、short questions and answers | 再加 verb + object + infinitive（give/take/send/bring/show + 双宾）、so/nor with auxiliaries |

**三个常见误收，务必排除**：

1. **第三条件句（type 3，If I had known, I would have called）不在 B1 范围**，属更高级别。
2. **过去完成时**两份官方大纲都没有列为必考时态（B1 手册的 Past perfect simple 只标 narrative / reported speech 用途），本项目维持「只认读」口径。
3. **虚拟语气进阶（wish / if only / would rather / mandative）** 不在 A2 或 B1 清单内。

**Handbook 自己的免责声明**：考生在文章里可能遇到清单之外的语法形式，但不会被直接考。清单是「考什么」的范围，不是阅读材料的天花板——查漏时不要把「阅读里出现过」当成「必须教」。

### 话题（Topics）

A2 官方列 **22 个话题**，B1 用同一套：Clothes、Daily life、Entertainment and media、Food and drink、Health medicine and exercise、Hobbies and leisure、House and home、Language、People、Personal feelings opinions and experiences、Personal identification、Places and buildings、School and study、Services、Shopping、Social interaction、Sport、The natural world、Transport、Travel and holidays、Weather、Work and jobs。

主手册第 45 章表 45-1 已建立「话题 → 本书章节」对照，查漏时先查这张表。

### 功能表达（Functions）

官方另有一类 functions，不是语法而是「什么场合说什么话」，KET 听力与口语几乎每场都考：请求、征求许可、提供、邀请、建议、道歉、感谢、同意与不同意、表达喜好与感受、问路、购物等。主手册 40.8 已收 14 组。

### 卷面结构

| 卷 | 项目 | 时长 | 结构 |
|---|---|---|---|
| A2 Key | Reading and Writing | 60 分钟 | 七部分：1–5 阅读（告示、便条、短信、简短说明），6 写短信/邮件 ≥25 词，7 看图写故事 ≥35 词 |
| | Listening | 约 30 分钟 | 五部分，短对话或短独白 |
| | Speaking | 双人 8–10 分钟 | 两部分：互问个人信息 + 看图完成任务 |
| B1 Preliminary | Reading | 45 分钟 | 六部分 |
| | Writing | 45 分钟 | 两篇各约 100 词：回邮件（四条提示都要答到）+ 文章或故事 |
| | Listening | 约 30 分钟 | 四部分 |
| | Speaking | 双人 10–12 分钟 / 三人 15–17 分钟 | 四部分 |

B1 写作评分四项：内容、交际完成度、组织、语言。B1 通过线为 Grade C（Cambridge Scale 140–152），Grade B 153–159，Grade A 160–170。英式卷与美式卷都接受 colour/color 这类对应拼写；本项目写作统一用英式。

## 三、查漏工作流

1. **确定层级**：这次要补的是小学档（★/○）、KET 档（◆）还是 PET 档（●）？
2. **对照官方清单**：语法项对照上面的 KET/PET 分界表；话题对照 22 项；功能表达对照 functions 清单。
3. **查现有覆盖**：用 `scripts/check_books.py` 先确认结构完好，再 grep 关键词判断是否已有专节（**注意区分「顺带提到」与「系统讲解」**：词表说明栏里出现一次不算覆盖，要有独立小节或表格才算）。
4. **判断该不该收**：落在边界外的（type 3、过去完成时系统讲解、虚拟语气进阶）明确不收，并在书里说明为什么不收。
5. **写入四本书**：按 book-map.md 的映射同步，主手册与 KET-PET 册都要写。
6. **复核**：再跑 `scripts/check_books.py`，然后重建 PDF。
