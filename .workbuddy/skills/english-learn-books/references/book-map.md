# 四本书的对应关系与同步规则

《小学英语辅导手册》是主册（合集），另外三本都从它派生。任何内容改动都要判断落在哪几本里，然后按本文件的映射同步。

---

## 一、四本书的定位

| 文件 | 定位 | 结构 | 规模 |
|---|---|---|---|
| `小学英语辅导手册.md` | **主册**，除初中册外的全部内容 | 六部分 49 章 | 约 211 页 |
| `小学英语-KET-PET辅导手册.md` | 面向考试的册子：小学词 + 记词方法 + 语法 + KET/PET 考纲 | 五部分 41 章 | 约 180 页 |
| `小学英语辅导手册-学生本.md` | 给孩子自学用，只留最核心的词 | 无部分，22 节（一、二、三…） | 约 35 页 |
| `自然拼读.md` | 单行本，只收拼读 | 8 章 | 约 21 页 |

另有 `初中英语学习辅导手册.md`，是**独立的另一本**，不参与本文件的同步关系（主册明确声明「初中阶段的词、广州中考卷面……在《初中英语学习辅导手册》，本书不重复」）。

## 四、同步工作流

### 主册 → 三本子书（内容更新下沉）

1. 判断改动落在哪个部分：
   - 第 1–8 章 → 同步 `自然拼读.md`（章号不变）+ KET-PET 册不涉及（它没有拼读部分）
   - 第 9–49 章 → 同步 KET-PET 册第 1–41 章（章号 **−8**）
   - 第 9–25 章的改动 → 另看学生本对应主题节（见 C 节）
2. **改写所有编号引用**：正文里的「第X章」「N.M」「表 N-M」必须按偏移换算，不能照抄。
3. **改写叙述句**：形如「前面第三部分讲的……」「上一章……」的句子，换序或换章号后会不成立，要逐句重写，不能只改数字。
4. **改指向拼读的引用**：主册里「第四章」「第六章」「第一部分」若指拼读，搬到 KET-PET 册后要改成《自然拼读》（见 B 节替换表）。
5. 重建三本书的目录（见 scripts 说明）。

### 三本子书 → 主册（内容更新上浮）

1. 先确认改动确实属于主册范围（学生本独有的排期表、口语化标题不上浮）。
2. 按映射把章号换算回主册编号：KET-PET 册 +8，自然拼读不变，学生本按主题对应（C 节）。
3. 检查主册是否已有同类内容，避免重复：
   - 若主册已讲过 → 子书改为指针（「详见主册 N.M」），不要两份正文
   - 若子书是新增 → 主册补全，子书可保留摘要
4. 主册前言若声明了部分数（「分六个部分」）、章数（「四十九章」），改动后要同步这些数字。

### 双向都要做的收尾

- 跑 `scripts/check_books.py`（含四书映射校验）
- 重建受影响书籍的 PDF
- 在被改的书的版本记录表加一行（`| 第N版 | YYYY/MM/DD | 说明 |`）

## 五、跨书引用规范

引用另一本书时用书名号 + 完整书名，不要写「主册」「那本书」：

```
详见《初中英语学习辅导手册》第十四章。
正文与《小学英语辅导手册》第一部分相同。
```

**同一本书内部**引用只写编号，不写书名：

```
构成与位置见 43.6、43.7。
时态按第二十五章表 25-18 准备。
```

## 六、历史踩坑（重排章节时必读）

1. **章标题替换丢前缀**：用正则替换 `## 第X章` 时若只替换匹配片段，会丢掉 `## `，标题降级成正文。lambda 里必须写 `'## ' + 新标题`。
2. **部分号全局替换误伤**：正文里「第六部分写一封短信」指的是 KET 卷面的第六部分，不是本书的第六部分。全局替换部分号会把它改错，必须按块或按行精确处理，并给卷面用语加白名单。
3. **跨块引用未重映射**：把 A 块搬到 B 位置时，A 块内部指向 C 块的引用（如「见 34.1」）如果 C 块也动了，就失效。搬完必须全文扫一遍编号引用。
4. **重排后叙述句失效**：「前面第三部分讲的联想」这类句子，在章节换序后指向错误。编号可以自动改，叙述句只能逐句重写。
5. **目录忘记重建**：章号一改，目录里的锚点全部失效（`check_books.py` 会报「目录链接无对应标题」）。目录必须用脚本重建，不要手改。
6. **重排前先备份**：跨块搬移容易一次搞坏多处，先 `cp` 一份到 `D:/tmp/`（注意 Git Bash 的 `/tmp` 与 Python 的路径解析不同，写脚本时用 `D:/tmp/`）；万一搞坏，`git checkout -- <file>` 可回到上次提交。
7. **章号 remap 不能分两次调用**：先 `remap(26,38,-8)` 再 `remap(9,25,-8)` 会把第一次的结果（18–25）再减一遍，出现「第十章 发散记忆法」。同一段文本的偏移必须**一次 remap 覆盖全部区间**（如 `remap(9,38,-8)`），或者用占位符把新章号与旧章号隔离后再还原。
8. **占位符要分中文数字与阿拉伯数字两类**：章号还原成 `二十六`，小节号与表号还原成 `26`。共用一个占位符会把 `### 26.1` 写成 `### 二十六.1`，Markdown 不再认它是标题，随后按 `### 26.x` 查找会失败并引发切片越界、整块重复。
9. **切片位置找不到时会静默复制整块**：`body.find(...)` 返回 −1 时，`body[-1:j]` 不报错而是从末尾切，容易把整段内容拼接两遍。取切片前必须 `assert i > 0`。
10. **标题紧贴表格末行会被 Markdown 吞掉**：`|...|` 行之后直接写 `### N.M 习题`（中间没有空行），Markdown 会把它当表格续行，渲染成 10pt 黑色正文、`###` 字面可见，标题因此不进书签也不进目录页码。补习题、补小节时最容易犯。`check_books.py` 的 `check_table_heading_gap` 会报错，构建日志会打印 `TOC without page: N.M 习题`。
11. **陈旧章号引用是「静默错误」**：章号平移后，「收在第三十一章」这类句子仍然指向一个存在的章，只是变成了别的章。编号校验和交叉引用校验都查不出来，只能人工通读前言、全文约定、各部分导语。扩充记词方法后就漏过四处（前言语法章号、● 标记的 PET 词表章号、◆ 汇总章号）。
